## 1. Краткое описание

**MeterSync** — это Android-приложение для автоматизации сбора и управления данными о счетчиках. Приложение предназначено для сотрудников коммунальных служб и контролеров счетчиков, которые работают с системой учета счетчиков.

Приложение обеспечивает:
- **Синхронизацию данных** о счетчиках с веб-платформы
- **Офлайн-доступ** к загруженным данным
- **Фотографирование счетчиков** с автоматическим нанесением информационных водяных знаков
- **Удобное управление** большим количеством адресов и счетчиков

Все данные хранятся локально на устройстве, что позволяет работать без постоянного подключения к интернету после первоначальной синхронизации.

## 2. Возможности

### Синхронизация данных
- Автоматическая загрузка списка адресов с веб-платформы
- Загрузка счетчиков для конкретного адреса
- Массовая загрузка всех счетчиков для всех адресов одним нажатием
- Обновление данных при необходимости

### Офлайн-доступ
- Локальное хранение всех данных в базе данных Room
- Работа с данными без подключения к интернету
- Быстрый доступ к информации о счетчиках

### Управление счетчиками
- Просмотр списка всех адресов с статистикой
- Детальный просмотр счетчиков для каждого адреса
- Отслеживание статусов счетчиков, цвет номера счетчика означает:
  - 🔴 Не проверен
  - 🟢 Проверен, не загружен
- Фильтрация счетчиков по статусам
- Поиск по адресам и номерам счетчиков

### Фотографирование счетчиков
- Создание фотографий счетчиков с помощью камеры устройства
- Автоматическое нанесение водяного знака с информацией о счетчике:
  - Номер счетчика
  - Адрес
  - Квартира/помещение
- Автоматическое сохранение фотографий в галерею устройства
- Отслеживание сфотографированных счетчиков через чекбоксы

### Статистика и аналитика
- Отображение общего количества адресов и счетчиков
- Статистика по статусам проверки счетчиков
- Процент выполнения проверки для каждого адреса

### Дополнительные функции
- Переключение между светлой и темной темой
- Полная очистка кэша и данных приложения

## 3. Требования

### Минимальные требования к устройству
- **Android версия:** 7.0 (API 24) или выше
- **Интернет:** Требуется для первоначальной синхронизации данных
- **Разрешения:**
  - Доступ к интернету (только для синхронизации)
  - Доступ к камере
  - Доступ к хранилищу (для сохранения фотографий)

## 4. Установка

### Установка через APK файл

1. **Скачайте APK файл** из папки [releases](releases/)
   - Рекомендуется использовать последнюю версию

2. **Разрешите установку из неизвестных источников:**
   - Откройте **Настройки** → **Безопасность** (или **Приложения**)
   - Включите опцию **"Разрешить установку из неизвестных источников"** или **"Установка неизвестных приложений"**
   - Выберите ваш файловый менеджер или браузер, через который будете устанавливать APK

3. **Установите приложение:**
   - Откройте скачанный APK файл
   - Нажмите **"Установить"**
   - Дождитесь завершения установки
   - Нажмите **"Открыть"** для запуска приложения

4. **Предоставьте необходимые разрешения:**
   - При первом запуске приложение запросит разрешения на:
     - Камеру (для фотографирования счетчиков)
     - Хранилище (для сохранения фотографий)

**Примечание:** Если у вас уже установлена более старая версия приложения, новая версия установится поверх существующей с сохранением всех данных.

## 5. Краткое руководство пользователя

### Первый запуск

1. **Вход в систему:**
   - При первом запуске заполните логин и пароль на вкладке **"Вход"**
   - Нажмите кнопку **"Вход"**
   - Приложение автоматически войдет в систему и загрузит список адресов

2. **Ожидание синхронизации:**
   - Процесс загрузки может занять некоторое время в зависимости от количества адресов
   - После завершения вы увидите количество адресов личного кабинета

### Работа с адресами

1. **Просмотр списка адресов:**
   - Перейдите на вкладку **"Список"**
   - Вы увидите все загруженные адреса
   - Для каждого адреса отображается:
     - Полный адрес
     - Количество счетчиков (после загрузки ПУ)
     - Количество проверенных счетчиков (после загрузки ПУ)
     - Процент выполнения (после загрузки ПУ)

2. **Поиск адресов:**
   - Используйте поле поиска вверху экрана
   - Поиск работает по адресу и номеру счетчика

3. **Загрузка счетчиков:**
   - Нажмите на адрес для просмотра детальной информации
   - Или используйте кнопку **"Загрузить все счетчики"** для массовой загрузки всех счетчиков

### Работа со счетчиками

1. **Просмотр счетчиков:**
   - Откройте адрес для просмотра списка счетчиков
   - Каждый счетчик отображается с:
     - Номером счетчика. Зеленый - акт составлен, красный - акт не составлен (на момент загрузки ПУ).
     - Информацией о квартире/помещении
     - Кнопкой камеры для фотографирования
	 - Чекбокс (см. пункт 5 "Отслеживание фотографий")

2. **Фильтрация счетчиков:**
   - Используйте переключатели фильтров:
     - **Все** — показать все счетчики
     - **Проверенные** — только проверенные счетчики
     - **Не проверенные** — только непроверенные счетчики

3. **Поиск счетчиков:**
   - Используйте поле поиска для поиска по квартире или номеру счетчика

4. **Фотографирование счетчиков:**
   - Нажмите кнопку камеры (фиолетовая кнопка) рядом с нужным счетчиком
   - Разрешите доступ к камере, если это первый раз
   - Сделайте фотографию счетчика
   - Фотография автоматически сохранится в галерею с водяным знаком
   - Чекбокс слева от кнопки камеры автоматически отметится
   - Водяной знак содержит:
     - Номер счетчика
     - Адрес
     - Квартиру/помещение

5. **Отслеживание фотографий:**
   - Чекбокс слева от кнопки камеры показывает, был ли счетчик сфотографирован
   - Чекбокс автоматически отмечается при фотографировании
   - Вы можете вручную снять отметку, если необходимо
   - Состояние сохраняется между сеансами работы
   - Помогает определить, в какой квартире уже был, облегчает повторный проход

### Обновление данных

1. **Обновление счетчиков для адреса:**
   - Необходим интернет
   - Откройте детальный экран нужного адреса
   - Нажмите кнопку **"Загрузить счетчики"**
   - Приложение загрузит актуальные данные с веб-платформы

2. **Массовая загрузка всех счетчиков:**
   - Необходим интернет
   - На экране списка всех адресов нажмите **"Загрузить все счетчики"**
   - Процесс может занять продолжительное время
   - Прогресс отображается на экране

### Настройки и управление

1. **Переключение темы:**
   - На экране входа внизу находится переключатель темы

2. **Управление логированием:**
   - **Для разработчика**
   - На экране входа включите/выключите логирование
   - Логи сохраняются в файл `metersync.log` в директории приложения
   - По умолчанию логирование отключено

3. **Очистка данных:**
   - На экране входа нажмите кнопку **"Удалить кэш"**
   - Это удалит все данные приложения:
     - Все адреса и счетчики
     - Сохраненные учетные данные
     - Кэш WebView
   - После очистки потребуется повторный вход

### Статистика

На экране входа отображается статистика:
- **Количество адресов** — общее число загруженных адресов
- **Количество счетчиков** — общее число счетчиков
- **Статистика по статусам:**
  - Не проверены
  - Проверены, не загружены
  - Загружены

### Советы по использованию

- **Офлайн-режим:** После первоначальной синхронизации вы можете работать с данными без интернета
- **Массовая загрузка:** Используйте массовую загрузку счетчиков, когда у вас есть стабильное интернет-соединение
- **Фотографирование:** Фотографии автоматически сохраняются в галерею, вы можете найти их в папке "Pictures" или "Camera"
- **Поиск:** Используйте поиск для быстрого нахождения нужных адресов или счетчиков
- **Фильтры:** Используйте фильтры для работы только с определенными статусами счетчиков
