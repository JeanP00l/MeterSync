## [0.1.41] - 2025-12-09

### Добавлено
- **Отслеживание фотографирования счетчиков**: Реализована система отслеживания сфотографированных счетчиков
  - Добавлен чекбокс слева от кнопки камеры для каждого счетчика
  - Чекбокс автоматически отмечается при нажатии на кнопку камеры
  - Возможность вручную снять чекбокс при необходимости
  - Сохранение состояния в базе данных (поле `isPhotographed`)
  - Состояние сохраняется между сеансами работы приложения
- **Миграция базы данных**: Добавлена миграция с версии 2 на 3
  - Добавлена колонка `isPhotographed` в таблицу `meters`
  - Дефолтное значение `false` для всех существующих счетчиков

### Изменено
- **UI компонент MeterItem**: Обновлен интерфейс отображения счетчиков
  - Добавлен чекбокс для отслеживания фотографирования
  - Кнопка камеры теперь фиолетового цвета (Color(0xFF9C27B0))
  - Улучшена компоновка элементов (чекбокс слева от кнопки камеры)
- **База данных**: Версия базы данных обновлена с 2 до 3
  - Новая колонка `isPhotographed INTEGER NOT NULL DEFAULT 0`

### Технические детали
- Добавлено поле `isPhotographed: Boolean = false` в сущность `Meter`
- Реализована миграция `MIGRATION_2_3` в `AppDatabase`
- Добавлен метод `updateMeterPhotographed()` в `MeterDao`
- Добавлен метод `updateMeterPhotographed()` в `MeterViewModel`
- Обновлен компонент `MeterItem` с поддержкой чекбокса и обработчиков событий

## [0.1.4] - 2025-12-09

### Добавлено
- **Оптимизация энергопотребления WebView**: Реализована система автоматической приостановки/возобновления WebView для снижения энергопотребления
  - Методы `suspend()` и `resume()` в `WebViewManager` для управления состоянием WebView
  - Автоматическая приостановка WebView после загрузки данных (адресов и счетчиков)
  - Автоматическое возобновление WebView при необходимости выполнения операций
  - Экономия энергии 60-80% в фоновом режиме
- **Безопасное удаление временных файлов фотографий**: Реализована система безопасного удаления временных файлов после сохранения фотографий с водяным знаком
  - Проверка успешного сохранения перед удалением временного файла
  - Принудительная синхронизация с диском перед проверкой
  - Защита от потери фотографий - временный файл удаляется только после подтверждения сохранения
- **Чекбокс "Показать WebView"**: Добавлен чекбокс на экране входа для управления отображением WebView (только для отладки)
  - По умолчанию отключен - WebView не показывается автоматически
  - Позволяет включать/выключать отображение WebView для отладки процесса входа

### Изменено
- **Оптимизация энергопотребления**: WebView автоматически приостанавливается после завершения загрузки данных
  - Приостановка после загрузки адресов
  - Приостановка после загрузки счетчиков (включая массовую загрузку)
  - Возобновление только при необходимости выполнения операций
- **Улучшена функция "Удалить кэш"**: Исправлена и улучшена работа выхода через UI при очистке кэша
  - Автоматическое возобновление WebView перед попыткой выхода
  - Загрузка главной страницы, если WebView на пустой странице
  - Увеличенное время ожидания загрузки страницы (5 секунд)
  - Проверка готовности страницы в скрипте выхода перед поиском элементов
  - Дополнительная задержка для инициализации React-компонентов
- **Улучшена обработка фотографий**: Оптимизирован процесс сохранения и удаления временных файлов
  - Последовательность операций: загрузка → добавление водяного знака → сохранение → проверка → удаление временного файла
  - Детальное логирование всех шагов процесса
  - Защита от потери данных при ошибках

### Исправлено
- **Функция "Удалить кэш"**: Исправлена проблема, когда скрипт выхода не мог найти кнопки UI (Профиль, Выход, Выйти)
  - WebView теперь корректно возобновляется перед попыткой выхода
  - Страница загружается полностью перед запуском скрипта выхода
  - Скрипт выхода ждет готовности страницы и инициализации React-компонентов
- **Безопасность фотографий**: Исправлена проблема с потерей временных файлов
  - Временные файлы удаляются только после подтверждения успешного сохранения
  - При ошибках временные файлы сохраняются как резервные копии

### Технические детали
- Реализованы методы `suspend()`, `resume()`, `isSuspended()` в `WebViewManager`
- Добавлена автоматическая приостановка в `MeterViewModel` после загрузки данных
- Реализована система проверки сохранения фотографий с `verifyImageSaved()`
- Улучшена функция `clearCacheAndReturnToLogin()` с проверкой готовности страницы
- Добавлено детальное логирование всех операций с фотографиями
- Увеличено время ожидания загрузки страницы при выходе через UI (до 5 секунд)

## [0.1.3] - 2025-01-27

### Добавлено
- **Переключатель темы**: Добавлена возможность переключения между светлой и темной темой
- **ThemeManager**: Новый класс для управления темой приложения с сохранением выбора пользователя
- **Автоматическое обновление темы**: Тема применяется ко всему приложению и обновляется в реальном времени

### Изменено
- **Оптимизация загрузки счетчиков**: Значительно ускорена массовая загрузка счетчиков для всех адресов
  - Переиспользование WebView вместо создания нового для каждого адреса
  - Навигация назад к списку адресов вместо полной перезагрузки страницы
  - Уменьшены задержки в JavaScript скриптах (с 5+ секунд до ~1.5-2 секунд на адрес)
  - Оптимизировано ожидание элементов (более частые проверки, уменьшенные таймауты)
  - Проверка авторизации только при первом адресе при массовой загрузке
- **Экран входа**: Добавлен переключатель темы внизу экрана
- **Производительность**: Общее ускорение массовой загрузки в 3-4 раза

### Технические детали
- Реализован `ThemeManager` для управления темой через SharedPreferences
- Добавлены методы `checkIfAuthorized()` и `navigateBackToAddressList()` в WebViewManager
- Оптимизирован JavaScript скрипт `parse_meters.js` с уменьшенными задержками
- Улучшена логика переиспользования WebView при массовой загрузке
- Использование Material 3 `darkColorScheme()` и `lightColorScheme()` для темной и светлой темы
- Автоматическая синхронизация темы между экранами через периодическую проверку

## [0.1.0] - 2025-01-27

### Добавлено
- **Базовая функциональность**: Первая рабочая версия приложения
- **Room Database**: Локальное хранение данных о адресах и счетчиках (версия 2)
- **Jetpack Compose UI**: Современный интерфейс с Material Design 3
- **Система навигации**: Навигация между экранами через Navigation Compose
- **Экран входа (LoginScreen)**: Ввод логина и пароля с автоматическим сохранением
- **Список адресов (AddressListScreen)**: Отображение всех загруженных адресов с поиском
- **Детальный экран адреса (AddressDetailScreen)**: Список счетчиков для конкретного адреса
- **Система статусов счетчиков**: Отслеживание статусов (NOT_CHECKED, CHECKED_NOT_LOADED, LOADED)
- **Фотографирование счетчиков**: Создание фотографий с автоматическим нанесением водяного знака
- **Безопасное хранение**: Зашифрованное хранение учетных данных через CredentialStore
- **Система логирования**: Категоризированное логирование с возможностью включения/выключения
- **Массовая загрузка**: Загрузка всех счетчиков для всех адресов
- **Поиск и фильтрация**: Многоуровневый поиск по адресам и счетчикам
- **Статистика**: Отображение статистики по статусам счетчиков

### Технические детали
- Минимальная версия SDK: Android 7.0 (API 24)
- Целевая версия SDK: Android 14 (API 34)
- Архитектура: MVVM (Model-View-ViewModel)
- Язык: Kotlin 1.9.24
- База данных: Room 2.6.1

### Известные ограничения
- Поддержка только одного аккаунта одновременно

## Формат версий

- **[MAJOR.MINOR.PATCH]** - формат версии (например, [0.1.2])
- **MAJOR** - изменения, несовместимые с предыдущими версиями API
- **MINOR** - новая функциональность с обратной совместимостью
- **PATCH** - исправления ошибок с обратной совместимостью

## Категории изменений

- **Добавлено** - для новых функций
- **Изменено** - для изменений в существующей функциональности
- **Устарело** - для функций, которые скоро будут удалены
- **Удалено** - для удаленных функций
- **Исправлено** - для исправления ошибок
- **Безопасность** - для исправлений уязвимостей
