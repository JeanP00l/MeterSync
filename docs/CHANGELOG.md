## [0.1.21] - 2025-01-27

### Исправлено
- **Критическое исправление кнопки "Удалить кэш"**: Исправлена некорректная работа кнопки очистки кэша, которая не сбрасывала веб-интерфейс к странице входа
- **Завершение сессии при очистке кэша**: Реализован корректный выход из личного кабинета через UI перед очисткой данных
- **Обновлены селекторы для выхода**: Обновлены CSS-селекторы кнопок выхода на актуальные версии (Профиль, Выход, Выйти)
- **Улучшена очистка WebView**: Добавлено полное уничтожение WebView перед созданием нового экземпляра
- **Сброс веб-интерфейса**: Теперь при очистке кэша WebView корректно сбрасывается к странице входа с полями логина и пароля

### Изменено
- **Метод clearCacheAndReturnToLogin()**: Полностью переработан с обновленными селекторами и улучшенной логикой ожидания элементов
- **Последовательность очистки кэша**: Изменен порядок операций - сначала выход через UI, затем уничтожение WebView, затем очистка данных
- **Ожидание загрузки элементов**: Добавлена проверка видимости элементов и автоматическая прокрутка перед кликом
- **Улучшена очистка базы данных**: Добавлено логирование для проверки успешного удаления адресов и счетчиков

### Технические детали
- Обновлены CSS-селекторы: `_navItem_fugwz_40`, `_listLink_cwmac_15`, `_button_alwez_1._full_alwez_187`
- Добавлена функция `scrollIntoView()` для прокрутки элементов в видимую область
- Увеличены таймауты ожидания элементов до 10 секунд
- Добавлена проверка текста кнопок для подтверждения правильности элементов
- Реализован метод `destroy()` в WebViewManager для полного уничтожения WebView
- Улучшена очистка данных через WebViewRestorePoint с удалением кэш-директорий

## [0.1.2] - 2025-01-27

### Добавлено
- **WebView интеграция**: Полная интеграция WebView для автоматизации взаимодействия с веб-платформой
- **Оптимизированный механизм входа**: Улучшенная система автоматического входа через WebView с поддержкой React-компонентов
- **WebViewManager**: Новый класс для управления жизненным циклом WebView и выполнения JavaScript скриптов
- **WebViewRestorePoint**: Система точек восстановления для возврата WebView к чистому состоянию
- **JavaScript интерфейс**: Bridge между Android и JavaScript для двусторонней коммуникации

### Изменено
- **Оптимизация кода входа**: Переработан скрипт автоматизации входа (`login.js`) для более надежной работы с React-формами
- **Улучшена обработка React-компонентов**: Добавлена поддержка React Hook Form через специальные методы активации полей
- **Улучшена обработка ошибок**: Расширена система обработки ошибок при работе с WebView
- **Логирование WebView**: Добавлено категоризированное логирование для отладки WebView операций

### Технические детали
- Реализован паттерн Listener для асинхронной обработки результатов JavaScript
- Добавлена поддержка ожидания загрузки DOM элементов с настраиваемыми таймаутами
- Улучшена обработка состояний загрузки страниц
- Оптимизирована работа с асинхронными операциями через Coroutines

### Исправлено
- Исправлена проблема с активацией React-полей ввода
- Улучшена стабильность автоматического входа в систему
- Исправлена обработка таймаутов при загрузке веб-страниц

## [0.1.1] - 2025-01-27

### Технические детали
- Оптимизирована работа с React-формами через специальные методы активации
- Улучшена обработка событий input, change, InputEvent для корректной работы React Hook Form
- Добавлен поиск и вызов обработчиков React Fiber для принудительного обновления состояния компонентов

## [0.1.0] - 2025-01-27

### Добавлено
- **Базовая функциональность**: Первая рабочая версия приложения
- **Room Database**: Локальное хранение данных о адресах и счетчиках (версия 2)
- **Jetpack Compose UI**: Современный интерфейс с Material Design 3
- **Система навигации**: Навигация между экранами через Navigation Compose
- **Экран входа (LoginScreen)**: Ввод логина и пароля с автоматическим сохранением
- **Список адресов (AddressListScreen)**: Отображение всех загруженных адресов с поиском
- **Детальный экран адреса (AddressDetailScreen)**: Список счетчиков для конкретного адреса
- **Система статусов счетчиков**: Отслеживание статусов (NOT_CHECKED, CHECKED_NOT_LOADED, LOADED)
- **Фотографирование счетчиков**: Создание фотографий с автоматическим нанесением водяного знака
- **Безопасное хранение**: Зашифрованное хранение учетных данных через CredentialStore
- **Система логирования**: Категоризированное логирование с возможностью включения/выключения
- **Массовая загрузка**: Загрузка всех счетчиков для всех адресов
- **Поиск и фильтрация**: Многоуровневый поиск по адресам и счетчикам
- **Статистика**: Отображение статистики по статусам счетчиков

### Технические детали
- Минимальная версия SDK: Android 7.0 (API 24)
- Целевая версия SDK: Android 14 (API 34)
- Архитектура: MVVM (Model-View-ViewModel)
- Язык: Kotlin 1.9.24
- База данных: Room 2.6.1

### Известные ограничения
- Поддержка только одного аккаунта одновременно
- Требуется интернет для синхронизации данных
- Зависимость от структуры веб-страницы

## Формат версий

- **[MAJOR.MINOR.PATCH]** - формат версии (например, [0.1.2])
- **MAJOR** - изменения, несовместимые с предыдущими версиями API
- **MINOR** - новая функциональность с обратной совместимостью
- **PATCH** - исправления ошибок с обратной совместимостью

## Категории изменений

- **Добавлено** - для новых функций
- **Изменено** - для изменений в существующей функциональности
- **Устарело** - для функций, которые скоро будут удалены
- **Удалено** - для удаленных функций
- **Исправлено** - для исправления ошибок
- **Безопасность** - для исправлений уязвимостей
