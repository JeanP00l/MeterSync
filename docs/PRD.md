## 1. Общее описание проекта

### 1.1 Назначение
MeterSync — это Android-приложение для автоматизации сбора и управления данными о счетчиках с веб-платформы `https://meter.printecs.com/`. Приложение обеспечивает офлайн-доступ к данным о счетчиках, позволяет фотографировать счетчики с автоматическим нанесением водяных знаков и предоставляет удобный интерфейс для работы с большим количеством адресов и счетчиков.

### 1.2 Целевая аудитория
- Сотрудники коммунальных служб
- Контролеры счетчиков
- Пользователи, работающие с системой учета счетчиков Printecs

### 1.3 Основные задачи, которые решает проект
- **Автоматизация входа**: Автоматический вход в систему через WebView с сохранением учетных данных
- **Синхронизация данных**: Автоматическая загрузка адресов и счетчиков с веб-платформы
- **Офлайн-доступ**: Локальное хранение всех данных для работы без интернета
- **Фотографирование счетчиков**: Создание фотографий с автоматическим нанесением информации о счетчике
- **Управление статусами**: Отслеживание статусов проверки и загрузки счетчиков
- **Удобный поиск**: Многоуровневый поиск по адресам и счетчикам

## 3. Основные разделы и функциональность

### 3.1 Экран входа (LoginScreen)
**Описание:** Экран для входа в систему и управления данными

**Функции:**
- Ввод логина и пароля
- Автоматическое сохранение учетных данных в зашифрованном виде
- Автоматический вход и синхронизация адресов при первом запуске
- Отображение статистики:
  - Количество загруженных адресов
  - Общее количество счетчиков
  - Статистика по статусам счетчиков (не проверены, проверены, загружены)
- Очистка кэша и всех данных приложения
- Управление логированием (включение/выключение)
- Переключатель темы (светлая/темная) - расположен внизу экрана

**Технические детали:**
- Использует `CredentialStore` для безопасного хранения
- `MeterViewModel` управляет процессом входа
- WebView автоматизирует процесс входа через JavaScript

### 3.2 Список адресов (AddressListScreen)
**Описание:** Главный экран со списком всех адресов

**Функции:**
- Отображение списка всех загруженных адресов
- Поиск по адресам и номерам счетчиков
- Отображение статистики для каждого адреса:
  - Общее количество счетчиков
  - Количество проверенных счетчиков
  - Процент выполнения
- Массовая загрузка всех счетчиков для всех адресов
- Навигация к детальному экрану адреса

**Технические детали:**
- Использует `LazyColumn` для эффективного отображения списков
- Реактивное обновление через Flow из Room
- Поддержка многоуровневого поиска

### 3.3 Детальный экран адреса (AddressDetailScreen)
**Описание:** Экран со списком счетчиков для конкретного адреса

**Функции:**
- Отображение всех счетчиков для выбранного адреса
- Поиск по квартире или номеру счетчика
- Фильтрация по статусам:
  - Все счетчики
  - Проверенные (CHECKED_NOT_LOADED + LOADED)
  - Не проверенные (NOT_CHECKED)
- Обновление списка счетчиков для адреса
- Фотографирование счетчиков с автоматическим нанесением водяного знака
- **Отслеживание фотографирования счетчиков (версия 0.1.41):**
  - Чекбокс слева от кнопки камеры для каждого счетчика
  - Автоматическая отметка чекбокса при нажатии на кнопку камеры
  - Возможность вручную снять чекбокс при необходимости
  - Сохранение состояния в базе данных между сеансами
- Цветовая индикация статусов:
  - 🔴 Красный — не проверен (NOT_CHECKED)
  - 🟢 Зеленый — проверен, не загружен (CHECKED_NOT_LOADED)
  - ☁️ Темно-зеленый — загружен (LOADED)

**Технические детали:**
- Использует `CameraManager` для работы с камерой
- Автоматическое нанесение водяного знака с информацией о счетчике
- Сохранение фотографий в галерею устройства
- Кнопка камеры фиолетового цвета (Color(0xFF9C27B0))
- Состояние чекбокса сохраняется в поле `isPhotographed` базы данных

### 3.4 Главный экран навигации (MainScreen)
**Описание:** Контейнер для навигации между экранами

**Функции:**
- Нижняя панель навигации с двумя вкладками:
  - "Вход" — экран входа
  - "Список" — список адресов
- Управление навигацией через Navigation Compose
- Передача контекста камеры между экранами

## 4. Архитектура данных

### 4.1 База данных (Room)
**Версия базы данных:** 3  
**Имя базы данных:** `metersync.db`

**Таблица: addresses**
- `id` (Long, PrimaryKey, AutoGenerate) — уникальный идентификатор
- `fullAddress` (String) — полный адрес
- `loadedAt` (Long) — время загрузки (timestamp)

**Таблица: meters**
- `id` (Long, PrimaryKey, AutoGenerate) — уникальный идентификатор
- `addressId` (Long) — связь с адресом (Foreign Key, неявная)
- `apartment` (String) — информация о квартире/помещении
- `meterNumber` (String) — номер счетчика (может содержать буквы)
- `status` (MeterStatus) — статус счетчика (добавлено в версии 2)
- `isPhotographed` (Boolean) — флаг фотографирования счетчика (добавлено в версии 3)
- `loadedAt` (Long) — время загрузки (timestamp)

**Enum: MeterStatus**
- `NOT_CHECKED` — не проверен (красный индикатор #D32F2F)
- `CHECKED_NOT_LOADED` — проверен, но не загружен (зеленый индикатор #388E3C)
- `LOADED` — загружен (темно-зеленый индикатор #2E7D32 с облачком)

**Миграции:**
- `MIGRATION_1_2`: Добавление колонки `status` в таблицу `meters` с дефолтным значением `NOT_CHECKED`
- `MIGRATION_2_3`: Добавление колонки `isPhotographed` в таблицу `meters` с дефолтным значением `false`

### 4.2 Безопасное хранение
- **CredentialStore** — использует EncryptedSharedPreferences для хранения логина и пароля
- Мастер-ключ шифрования через AES256_GCM

### 4.3 Управление темой
- **ThemeManager** — управление темой приложения (светлая/темная)
- Сохранение выбора пользователя в SharedPreferences
- Автоматическое применение темы ко всему приложению через MaterialTheme
- Использование Material 3 `darkColorScheme()` и `lightColorScheme()`
- Переключатель темы на экране входа

### 4.4 WebView автоматизация
**JavaScript скрипты:**
- `login.js` — автоматизация входа в систему (встроен в MeterViewModel)
- `parse_addresses.js` — парсинг списка адресов (встроен в MeterViewModel)
- `parse_meters.js` — парсинг счетчиков для адреса (встроен в MeterViewModel)

**Особенности:**
- Ожидание загрузки элементов через `waitForElement` с настраиваемыми таймаутами
- Обработка React-компонентов через специальные методы `setReactInputValueForElement`
- Определение статусов счетчиков по SVG-иконкам на странице (цвет и форма)
- Восстановление состояния WebView через `WebViewRestorePoint`
- Создание точки восстановления при первом запуске
- Полная очистка WebView данных при выходе из системы
- Поддержка UI-based logout sequence через JavaScript
- **Оптимизации производительности (версия 0.1.3):**
  - Переиспользование WebView для всех адресов при массовой загрузке
  - Навигация назад к списку адресов через `navigateBackToAddressList()`
  - Проверка авторизации через `checkIfAuthorized()` только при первом адресе
  - Уменьшенные задержки в JavaScript скриптах (с 5+ секунд до ~1.5-2 секунд)
  - Оптимизированное ожидание элементов (проверка каждые 200ms вместо 400ms)
- **Оптимизации энергопотребления (версия 0.1.4):**
  - Автоматическая приостановка WebView после загрузки данных
  - Методы `suspend()` и `resume()` для управления состоянием WebView
  - Экономия энергии 60-80% в фоновом режиме
  - Безопасное удаление временных файлов фотографий
  - Улучшенная функция "Удалить кэш" с корректным выходом через UI

**Особенности скрипта входа:**
- Прямой поиск input элементов по `id` и `name` атрибутам (`input#login`, `input#Пароль`)
- Ожидание появления полей ввода с таймаутом до 10 секунд (50 попыток по 200мс)
- Дополнительная задержка 1 секунда после обнаружения элементов для полной инициализации React
- Клики на контейнеры полей (`div._inputContainer_ydbik_41`) для активации React-компонентов
- Множественные клики (3 раза) на каждое input поле перед вводом данных для надежной активации
- Использование нативного setter для установки значений в React-компоненты
- Генерация всех необходимых событий (input, change, InputEvent) для корректной работы React Hook Form
- Поиск и вызов обработчиков React Fiber для принудительного обновления состояния компонентов

## 9. Ограничения и известные проблемы

### 9.1 Ограничения
- Поддержка только одного аккаунта одновременно
- Требуется интернет для синхронизации данных
- Зависимость от структуры веб-страницы (может сломаться при изменении сайта)

### 9.2 Известные особенности
- JavaScript селекторы зависят от CSS классов React-приложения (например, `._taskItem_36r29_38`, `._inputContainer_ydbik_41`)
- Статусы счетчиков определяются по SVG-иконкам на странице (цвет и форма пути)
- WebView требует времени для полной загрузки DOM (используются задержки 1-8 секунд)
- При первом запуске создается точка восстановления WebView
- Логирование по умолчанию отключено для экономии ресурсов
- Поддержка только одного аккаунта (требуется полная очистка для смены аккаунта)
- Поля входа в React-приложении требуют множественных кликов и активации контейнеров для корректной работы
- Структура полей входа: `<div class="_inputContainer_ydbik_41"><input id="login" />` для логина и `<div class="_inputContainer_ydbik_41"><input id="Пароль" />` для пароля

## 12. История изменений

### Версия 0.1.41 (2025-12-09)
- **Отслеживание фотографирования счетчиков**: Реализована система отслеживания сфотографированных счетчиков
  - Добавлен чекбокс слева от кнопки камеры для каждого счетчика
  - Чекбокс автоматически отмечается при нажатии на кнопку камеры
  - Возможность вручную снять чекбокс при необходимости
  - Сохранение состояния в базе данных (поле `isPhotographed`)
  - Состояние сохраняется между сеансами работы приложения
- **Миграция базы данных**: Добавлена миграция с версии 2 на 3
  - Добавлена колонка `isPhotographed` в таблицу `meters`
  - Дефолтное значение `false` для всех существующих счетчиков
- **Обновление UI**: Улучшен интерфейс отображения счетчиков
  - Кнопка камеры теперь фиолетового цвета
  - Добавлен чекбокс для визуального отслеживания фотографирования

### Версия 0.1.4 (2025-12-09)
- **Оптимизация энергопотребления**: Реализована система автоматической приостановки/возобновления WebView
  - Автоматическая приостановка WebView после загрузки данных (адресов и счетчиков)
  - Экономия энергии 60-80% в фоновом режиме
  - Методы `suspend()` и `resume()` для управления состоянием WebView
- **Безопасность фотографий**: Реализована система безопасного удаления временных файлов
  - Проверка успешного сохранения перед удалением временного файла
  - Защита от потери фотографий - временный файл удаляется только после подтверждения сохранения
- **Улучшена функция "Удалить кэш"**: Исправлена работа выхода через UI при очистке кэша
  - Автоматическое возобновление WebView перед попыткой выхода
  - Увеличенное время ожидания загрузки страницы
  - Проверка готовности страницы в скрипте выхода перед поиском элементов
- **Чекбокс "Показать WebView"**: Добавлен для управления отображением WebView (только для отладки)
  - По умолчанию отключен - WebView не показывается автоматически

### Версия 0.1.3 (2025-01-27)
- **Оптимизация производительности**: Значительно ускорена массовая загрузка счетчиков (в 3-4 раза быстрее)
  - Переиспользование WebView для всех адресов вместо создания нового для каждого
  - Навигация назад к списку адресов вместо полной перезагрузки страницы

  - Оптимизировано ожидание элементов с более частыми проверками
  - Проверка авторизации только при первом адресе при массовой загрузке
- **Переключатель темы**: Добавлена возможность переключения между светлой и темной темой
  - Переключатель расположен внизу экрана "Вход"
  - Автоматическое применение темы ко всему приложению
  - Сохранение выбора пользователя в SharedPreferences
- **ThemeManager**: Новый класс для управления темой приложения
- **Улучшена производительность**: Общее ускорение массовой загрузки счетчиков
