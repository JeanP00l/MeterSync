# MeterSync v0.1 - Release Notes

## Основные возможности

### 🔐 Управление аккаунтами
- **Ограничение на один аккаунт**: Приложение поддерживает работу только с одним аккаунтом одновременно. Если необходимо переключиться на другой аккаунт, потребуется переустановить приложение или выполнить полный сброс данных приложения.

### 📊 Синхронизация данных
- **Выгрузка всех счетчиков**: Возможность выгрузить информацию обо всех счетчиках, расположенных на всех адресах, связанных с вашим аккаунтом.

### 🔍 Поиск и навигация
- **Вложенный поиск**: Реализован многоуровневый поиск, позволяющий искать как по адресам, так и по отдельным счетчикам. Это значительно упрощает навигацию при работе с большим количеством данных.

### 📸 Фотографирование счетчиков
- **Фотографии с водяным знаком**: Для каждого счетчика можно сделать фотографию с нанесенным водяным знаком. Чтобы сделать фото, нажмите на фиолетовый кружок, расположенный справа от счетчика.

### ⚠️ Индикация статуса счетчиков
- **Красный номер счетчика**: Если номер счетчика отображается красным цветом, это означает, что акт не был оформлен или загружен на момент последней синхронизации счетчиков и адресов в приложении. Это помогает быстро определить, какие счетчики требуют внимания.

### 📈 Статистика
Приложение ведет подробный подсчет:
- **Общее количество счетчиков**: Отображается общее число всех счетчиков в системе
- **Выполненные счетчики**: Количество счетчиков, которые были успешно обработаны во время синхронизации
- **Невыполненные счетчики**: Количество счетчиков, которые требуют дополнительного внимания или обработки
- **Количество адресов**: Общее число адресов, связанных с вашим аккаунтом

## Установка

1. Скачайте APK файл из раздела "Assets" этого релиза
2. На вашем Android устройстве разрешите установку из неизвестных источников (если требуется)
3. Установите APK файл
4. При первом запуске войдите в свой аккаунт

## Технические детали

- **Версия**: 0.1
- **Минимальная версия Android**: 7.0 (API 24)
- **Целевая версия Android**: 14 (API 34)

## Примечания

- APK файл подписан цифровой подписью для безопасной установки
- Приложение требует подключения к интернету для синхронизации данных
- Для работы с фотографиями требуется разрешение на доступ к камере
